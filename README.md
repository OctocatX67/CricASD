# CricASD — Unity 3D Cricket Game Starter

A Unity 3D cricket starter using a Mixamo batsman, cube bowler, physics-based ball, and keyboard controls.

## Controls

- **B** : Bowl the ball
- **Space** : Swing the bat

## Setup

1. Open the project in Unity.
2. Import a Mixamo batsman character + bat animation, add to the scene at (0,1,4).
3. Create the Pitch (plane), Ball (sphere at 0,0.25,-3.5), Bowler (cube at 0,1,-4), UI Canvas (ScoreText/BallText), and GameManager.
4. Add the scripts from `/Assets/Scripts` as described.
5. Use the inspector script references (Animator, Ball, ScoreManager, UI Text, etc.).
6. Set up the Animator as above (Trigger “Bat” plays swing animation).
7. Press Play and bat away!
